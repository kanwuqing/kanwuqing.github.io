数学与物理的结合——带权将军饮马

Kanwuqing2026-03-072026-06-20

警告: 本文可能包含大量不规范的物理术语以及物理思想

1 情境引入与描述

做题的时候, 遇到一道形如 \(\begin{vmatrix}AP\end{vmatrix}+2\begin{vmatrix}BP\end{vmatrix}\) 最小值的问题, 其中 \(A(1,3), B(4, 0)\) 是平面上固定的两点, \(P\) 点在 \(y\) 轴上

如果没有 \(\begin{vmatrix}BP\end{vmatrix}\) 前这个系数, 那么这就是一道很简单的几何题, 但是有了这个系数, 就很烦, 当然这道题可以设出坐标, 用两点间距离公式列出函数解析式硬导, 发现驻点为1, 但是显然有更为优雅的做法

2 考虑简单情况 (无系数)

不妨设想一下当没有系数的情况, 我们可以找点 \(B\) 关于定直线 (此处为 \(y\) 轴) 的对称点 \(B^\prime(-4,0)\), 那么 \(\begin{vmatrix}AP\end{vmatrix}+\begin{vmatrix}BP\end{vmatrix}\), 这时问题就转化为了求 \(\begin{vmatrix}AP\end{vmatrix}+\begin{vmatrix}BP\end{vmatrix}\) 的最小值, 常识告诉我们当且仅当 \(A,P,B\) 三点共线时上式的值最小, 这可以用三角形三边关系等轻易证明, 但我们要考虑的是从光学角度来看这个问题, 当一束光从 \(A\) 点出发, 在介质相同的条件下, 其达到B点的路径必为线段 \(AB\), 费马原理提出, 光从一点到另一点总是沿着时间最短的路径传播, 两点之间, 线段最短, 那么就很好的证明了上述常识中的结论

3 拓宽

我们尝试拓宽至题目中的情形, 显然在这个状态下传播路径不再是直线, 反证法易证. 在未加权的版本中, 介质相同 (不妨设均为真空, 光速为 \(c\)), 那么现在一条定直线将整个空间分割为2部分, 我们假设 \(A\) 点所在的那一半为真空 (光速最快, \(v_入=c\)), 另外一边为介质 \(J\), 光速为 \(v_出\)

此时 \(B\) 点有两种状况, 即与 \(A\) 点在同侧或异侧, 根据对称性, 我们不妨假设 \(B\) 点在同侧, \(B^\prime\) 在异侧. 那么光要从 \(A\) 传播到 \(B^\prime\), 其必会经过介质分界线, 此时光的路径与分界线的交点就是所求 \(P\) 点

要求光传播所用时间, 我们可以轻易写出 \(t_总=\begin{vmatrix}AP\end{vmatrix}/v_入+\begin{vmatrix}BP\end{vmatrix}/v_出\), 而我们需要的是 \(\begin{vmatrix}AP\end{vmatrix}+k\begin{vmatrix}BP\end{vmatrix}\) 的形式, 那么不妨令 \(v_入=1, v_出=\dfrac{1}{k}\), 根据折射率性质 (还是定义来着, 反正这里能用🙃) \[n(折射率)=\dfrac{v_入}{v_出}=k=\dfrac{sin入射角}{sin出射角}\] 我们可以相对轻易表示出入射角和出射角的正弦值, 那么根据这个列方程再解就轻松得多

4 实例

拿上面提到的情况举例: 假设 \(P(0,y_0)\), \(sin_{入射角}=\dfrac{3-y_0}{\sqrt{1+(3-y_0)^2}}, sin_{出射角}=\dfrac{y_0}{\sqrt{4+y_0^2}}, \dfrac{sin_{入射角}}{sin_{出射角}}=k\), 可以轻易解得 \(y_0=1\), 即 \(P(0,1)\), 与求导法结果相同

5 较为鲁棒的公式推导过程

不要死记!

5.1 坐标变换: 将直线化为 \(x\) 轴

设直线 \(l\) 的一般式为 \[ ax + by + c = 0 \quad (a^2 + b^2 \neq 0). \]

其方向向量为 \((\dfrac{-b}{\sqrt{a^2 + b^2}}, \dfrac{a}{\sqrt{a^2 + b^2}})\), 要将其变换至 \(x\) 轴, 需要旋转 \(\arctan \dfrac{a}{b}\), 即旋转矩阵为

\[ R = \begin{bmatrix} \dfrac{b}{\sqrt{a^2 + b^2}} & \dfrac{-a}{\sqrt{a^2 + b^2}} \\ \dfrac{a}{\sqrt{a^2 + b^2}} & \dfrac{b}{\sqrt{a^2 + b^2}} \end{bmatrix}. \]

这里不知道怎么回事的可以来这里看看

引入新坐标系 \((X, Y)\), 定义变换: \[ \begin{cases} X = \dfrac{bx - ay}{\sqrt{a^2 + b^2}}, \\[1em] Y = \dfrac{ax + by + c}{\sqrt{a^2 + b^2}}. \end{cases} \] 这是一个等距变换（旋转加平移）, 保持两点间距离不变.在新坐标系中, 直线 \(l\) 的方程为 \(Y = 0\)（因为直线上点满足 \(ax+by+c=0\), 故 \(Y=0\)）.点 \(A(x_1, y_1)\) 和 \(B(x_2, y_2)\) 变换后的坐标分别为 \[ A'(X_1, Y_1),\quad B'(X_2, Y_2), \] 其中 \[ X_i = \frac{b x_i - a y_i}{\sqrt{a^2+b^2}},\quad Y_i = \frac{a x_i + b y_i + c}{\sqrt{a^2+b^2}} \quad (i=1,2). \] 由于 \(A\)、\(B\) 在直线两侧, \(Y_1\) 与 \(Y_2\) 异号, 不妨设 \(Y_1 > 0\), \(Y_2 < 0\).

5.2 在新坐标系中建立方程

动点 \(P\) 在直线 \(Y=0\) 上, 设其坐标为 \((X, 0)\), 且显然 \(X \in [min\{X_1, X_2\},max\{Y_1,Y_2\}]\).则

\[ A'P = \sqrt{(X_1 - X)^2 + Y_1^2},\quad B'P = \sqrt{(X_2 - X)^2 + Y_2^2}. \] 入射角 \(\theta_1\) 是 \(A'P\) 与法线（即 \(Y\) 轴正方向）的夹角, 其正弦等于 \(A'P\) 在水平方向的分量除以斜边: \[ \sin\theta_1 = \frac{|X_1 - X|}{A'P}. \] 同理, 折射角 \(\theta_2\) 的正弦为 \[ \sin\theta_2 = \frac{|X_2 - X|}{B'P}. \] 根据费马原理, 极值点满足 \[ \frac{\sin\theta_1}{\sin\theta_2} = k. \] 代入得 \[ \frac{|X_1 - X|}{A'P} = k \frac{|X_2 - X|}{B'P}. \tag{1} \]

5.3 平方消去绝对值

将 (1) 两边平方: \[ \frac{(X_1 - X)^2}{(X_1 - X)^2 + Y_1^2} = k^2 \frac{(X_2 - X)^2}{(X_2 - X)^2 + Y_2^2}. \tag{2} \] 交叉相乘: \[ (X_1 - X)^2 \left[ (X_2 - X)^2 + Y_2^2 \right] = k^2 (X_2 - X)^2 \left[ (X_1 - X)^2 + Y_1^2 \right]. \] 展开并移项: \[ (1 - k^2)(X_1 - X)^2 (X_2 - X)^2 + Y_2^2 (X_1 - X)^2 - k^2 Y_1^2 (X_2 - X)^2 = 0. \tag{3} \] 这是关于 \(X\) 的四次方程.

5.4 特殊情况 \(k = 1\)

当 \(k = 1\) 时, (3) 式化为 \[ Y_2^2 (X_1 - X)^2 = Y_1^2 (X_2 - X)^2. \] 开方得 \[ |Y_2|\,|X_1 - X| = |Y_1|\,|X_2 - X|. \] 由于 \(Y_1 > 0\), \(Y_2 < 0\), 故 \(|Y_2| = -Y_2\).合理选取符号（考虑几何意义, 通常取 $ -Y_2 (X_1 - X) = Y_1 (X_2 - X)$）, 解得 \[ X = \frac{-Y_2 X_1 - Y_1 X_2}{-Y_2 - Y_1}. \tag{4} \] 这也是经典将军饮马问题中利用对称点求得的交点横坐标

5.5 求解最小值

解方程 (3) 得到实根 \(X\)（可能多个）, 代入 \[ f_{\min} = \sqrt{(X_1 - X)^2 + Y_1^2} + k \sqrt{(X_2 - X)^2 + Y_2^2} \]

5.6 逆变换回原坐标系

设求得的 \(X\) 为极值点在新系中的横坐标, 则 \(P\) 在新系中为 \((X, 0)\).通过逆变换得到原坐标 \((x, y)\).

\[ x = \frac{bX + a\left(Y - \frac{c}{\sqrt{a^2+b^2}}\right)}{\sqrt{a^2+b^2}},\quad y = \frac{-aX + b\left(Y - \frac{c}{\sqrt{a^2+b^2}}\right)}{\sqrt{a^2+b^2}}. \] 对于 \(P\) 点, \(Y=0\), 代入得: \[ \begin{cases} x_P = \dfrac{bX - \dfrac{ac}{\sqrt{a^2+b^2}}}{\sqrt{a^2+b^2}} = \dfrac{bX}{\sqrt{a^2+b^2}} - \dfrac{ac}{a^2+b^2}, \\[1em] y_P = \dfrac{-aX - \dfrac{bc}{\sqrt{a^2+b^2}}}{\sqrt{a^2+b^2}} = -\dfrac{aX}{\sqrt{a^2+b^2}} - \dfrac{bc}{a^2+b^2}. \end{cases} \] 或者写为: \[ x_P = \frac{bX}{\sqrt{a^2+b^2}} - \frac{ac}{a^2+b^2},\quad y_P = -\frac{aX}{\sqrt{a^2+b^2}} - \frac{bc}{a^2+b^2}. \] 这就是原坐标系中 \(P\) 的坐标.
