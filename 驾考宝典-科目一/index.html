扣分专项

1分 禁、灯、掉、会、安、检 ①违反禁令标志/标线；②不按规定用灯；③普通公路掉头/倒车；④不按规定会车；⑤不系安全带；⑥检验不合格（客运危险品除外）。 3分 让、道、超、装、电、警、低 ①不让行（校车/行人/车辆）；②穿插变道、占对向车道、高速不按规定车道行驶；③超车/借道/穿插；④不按规定装号牌（少拧螺丝）；⑤电话；⑥故障不放警告标志/灯光；⑦高速低于最低时速。 6分 占、扣、轻、信 ①占应急车道；②扣证期间开车；③轻微伤逃逸（不犯罪）；④违反信号灯。 9分 停车、不符、没号牌 ①高速/快速路违停车、超4小时未休息；②准驾车型不符；③没号牌（未挂/遮挡/污损）。(疲劳驾驶) 12分 酒、伪、亡、重、反 ①酒驾；②伪造变造证照/号牌；③轻伤以上亡逃逸（不犯罪）；④致人重伤/死亡事故；⑤反向行驶（高速倒车/逆行/掉头）。

处罚专项

虚假材料申领驾照（虚情假1） 500元 1年内不得申请 欺骗、贿赂（两个贝）取得驾照 2000元 3年内不得申请 组织他人代替参加审验（组审） 3倍罚款（最高2万） —— 代替他人参加审验（代2） 2000元 —— 组织作弊（考试舞弊） —— 3年以下有期徒刑；情节严重：3~7年 组织谋取经济利益（买卖分等） 3~5倍罚款（最高10万） —— 审验弄虚作假: 1k元 代罚35

超载专项

🚗 超员（载人）题：口诀“下36，上69，看到100全扣光” 校车 / 公路客运 / 旅游客运：<20% → 6分；≥20% → 12分

7座以上（不含校车等）：20%-50% → 6分；50%-100% → 9分；>100% → 12分

7座以下：20%-50% → 3分；50%-100% → 6分；>100% → 12分

记忆要点：7座以下从3分起步；7座以上从6分起步；超100%都是12分。

🚚 超载（货车）题：口诀“136” 货车只看载重比例：<30% → 1分；30%-50% → 3分；50%-100% → 6分；>100% → 12分

🏎️ 超速题：分清“普通车”和“特殊车” 普通私家车：普通道路 20%-50% → 3分，>50% → 6分；高速/快速路 20%-50% → 6分，>50% → 12分

校车/中型以上客货车/危险品车：普通道路 10%-20% → 1分，20%-50% → 6分，>50% → 9分；高速/快速路 <20% → 6分，≥20% → 12分

记忆要点：特殊车在普通道路超速也有分（1,6,9）；只要在高速/快速路超20%就是12分。
